처음이라면 1번부터 시작하세요.

예상 학습 시간 약 90–150분 · 제작자의 대략적인 예상입니다. 확인 문제를 풀며 자신의 속도로 나누어 진행하세요.

각 단원은 용어와 이유를 설명한 뒤 조작 지시, 예상 관찰, 결과 해설과 확인 문제로 이어집니다. 선택 상자·슬라이더·체크 상자를 바꾸면 그림과 수치가 함께 바뀝니다. 색과 함께 문자·선 모양을 사용하므로 색만 보고 판단할 필요가 없습니다.

  1. 바꾸기 전에 어떤 선이나 수치가 달라질지 예상합니다.
  2. 한 조건만 바꾸고 결과 문장을 읽습니다. 실험 5는 검사 후 변환, 실험 13은 수정 후 다시 채우기가 필요합니다.
  3. 초기화로 되돌리고 다른 조건과 비교합니다. 확인 문제의 답을 먼저 생각한 뒤 펼칩니다.
  4. 출처 링크에서 해당 강의와 원문 교정 이유를 확인합니다.

다운로드한 폴더의 index.html을 직접 열면 됩니다. 8개 HTML과 style.css·model.js·app.js를 같은 폴더에 보관하세요. 인터넷 없이 실험할 수 있고 설치·로그인·데이터 전송이 없습니다. 원강의·공식 문서 링크를 열 때는 인터넷이 필요합니다.

SCOPE & EVIDENCE

확인한 강의와 빈 구간을 구분했습니다.

확인 자료는 105–110, 130–135, 137–143의 19강입니다. 요청 범위의 111–129 및 136, 총 20강은 로컬 노트·전사를 찾지 못했습니다. 빠진 강의 내용을 임의로 복원하지 않았습니다.

기초 용어·배치·배선 원리는 본문에, EasyEDA 작업은 원리를 설명하는 사례로, 특정 수치·설정은 해당 보드의 조건으로 옮겼습니다. 교재의 수식·프리셋·검사 절차는 학습을 위한 추가 모형이며 실제 CAD나 전기·열 해석기가 아닙니다.

인버터 하드웨어 강의 예시 A와 소형보드 B의 부품·션트·이득은 서로 섞지 않습니다. 벅 도식, 2선 측정 산술, NTC 원리, 단위 표기와 과도한 일반화는 원자료와 공식 문서에 근거해 교정했습니다.
