그림에서 연결 의도로

심볼과 풋프린트를 맞추고, 넷을 정의하고, 검사한 회로도를 PCB로 넘깁니다. EasyEDA 메뉴는 강의 당시 예이며 도구 버전에 따라 달라질 수 있습니다.

한국어 · 오프라인 실험강의 기반 + 교정 해설제조·EMC 검증 도구 아님
EXPERIMENT 03

외형만 맞으면 같은 풋프린트일까요?

심볼(symbol)은 회로의 논리 기호이며, 풋프린트(footprint)는 실제 패드의 크기·간격·번호를 정의합니다. 라이브러리 부품을 선택했더라도 부품 데이터시트의 핀 번호와 풋프린트 패드 번호를 대조해야 합니다.

여기서는 학습용 2핀 커넥터를 사용합니다. 심볼 pin 1=GND, pin 2=+5V라고 정했습니다. 풋프린트의 1·2 매핑이 뒤바뀌면 모양이 같아도 전원을 거꾸로 연결할 수 있습니다.

직접 바꿔 보기학습용 SVG 모형

해 보기: 올바른 패키지에서 매핑을 뒤집어 보고, 다른 패키지도 선택하세요.
예상 관찰: 패키지 일치와 핀 일치는 별도로 판정됩니다.

실험 그림을 준비합니다.

핀 번호는 부품의 실제 기준입니다. 임의로 회전했다고 번호가 자동으로 바뀌는 것이 아닙니다. 극성·pin 1 표식·데이터시트 치수·실장 방향을 함께 확인합니다.

확인 문제 · 2D 그림이 비슷하면 부품 교체가 가능할까요?

외형뿐 아니라 패드 치수·피치·핀 매핑·전기적 사양까지 맞아야 합니다.

근거: 106강 4:12–5:55 · 130강 컴포넌트·Footprint Manager · 원문 교정·모형 경계

EXPERIMENT 04

같은 넷 이름은 연결 의도, 구리는 별도입니다.

넷 라벨(net label)은 회로도에서 떨어진 지점도 같은 연결로 묶습니다. 아래 실습은 같은 문서 범위에 있는 두 라벨을 비교합니다. 실제 도구에서는 로컬·계층·글로벌 라벨의 범위도 확인해야 합니다.

회로도에서 같은 이름인 두 지점은 PCB로 넘길 연결 목록에 들어갑니다. 그러나 보드에서는 트레이스·비아·플레인으로 실제 경로를 만들어야 합니다.

직접 바꿔 보기학습용 SVG 모형

해 보기: 두 라벨을 같게 만든 뒤 배선 완료를 켜세요. 이후 하나만 GND로 바꿔 보세요.
예상 관찰: 라벨 일치와 PCB 연결 완료가 서로 다른 상태로 표시됩니다.

실험 그림을 준비합니다.

이 실습의 배선 완료는 같은 넷의 두 끝점을 연결했다는 뜻입니다. 다른 넷을 강제로 구리로 붙이면 정상 연결이 아니라 쇼트이며 실제 DRC에서 검토해야 합니다.

확인 문제 · 라벨을 붙이면 보드가 자동으로 배선될까요?

아닙니다. 연결 의도를 전달할 뿐이며 실제 구리 경로를 설계하고 확인해야 합니다.

근거: 106강 5:55–7:29 · 131강 Net Flag 설명 · 원문 교정·모형 경계

EXPERIMENT 05

검사하고 옮기고, 다시 확인합니다.

기본 흐름은 회로도 작성 → 연결·부품 검사 → PCB 업데이트 → 배치·배선 → 다시 검사입니다. DRC(Design Rule Check)는 정한 규칙의 위반을 찾는 기능입니다. 도구에 따라 회로도 전기 규칙 검사를 ERC라고 부르기도 합니다.

이 모형은 풋프린트 누락과 의도한 넷의 끊김 두 가지만 검사합니다. PCB 업데이트는 검사한 최신 상태에 대해서만 허용하며, 변환 후에도 에어와이어를 실제 배선해야 합니다.

직접 바꿔 보기학습용 SVG 모형

해 보기: 누락 상태로 검사한 뒤 항목을 고쳐 다시 검사하고 PCB로 넘기세요.
예상 관찰: 오류가 사라지면 부품과 에어와이어가 PCB 쪽에 나타납니다. 변경하면 검사 결과가 오래된 상태가 됩니다.

실험 그림을 준비합니다.

Gerber는 제조용 구리·마스크 등 도형 데이터, BOM은 부품 목록입니다. 조립에는 위치·방향 데이터와 제조사 요구 파일도 필요할 수 있습니다. DRC가 통과해도 회로 기능, 부품 정격, 방열, EMC, 기구 간섭을 모두 확인한 것은 아닙니다.

확인 문제 · DRC 오류가 0이면 바로 제조해도 될까요?

설정된 규칙만 통과한 것입니다. 회로·풋프린트·기구·제조 요구조건을 별도로 검토해야 합니다.

근거: 106강 7:29–9:17 · 130강 DRC·PCB 변환·파일 추출 · 원문 교정·모형 경계
