PCB STUDY / 전원이 지나가는 회로

전원이 지나가는 회로

벅·MCU 주변부·인버터를 한눈에 읽되, 실제 부품과 수치는 확인된 보드 판본에 묶어 이해합니다.

한국어 · 오프라인 실험강의 기반 + 교정 해설제조·EMC 검증 도구 아님
EXPERIMENT 06

벅에서는 스위치가 꺼져도 인덕터 전류가 이어집니다.

벅(buck)은 입력보다 낮은 DC 전압을 만드는 스위칭 변환기입니다. TPS54360 사례는 내부 상단 스위치, SW 노드, 출력 인덕터 L, 외부 환류 다이오드, 출력 커패시터와 피드백으로 읽습니다. 피드백은 출력을 관찰해 제어기에 되돌리는 경로입니다.

ON 동안 입력에서 스위치와 인덕터를 거쳐 출력으로 흐릅니다. OFF 동안에는 인덕터 전류가 같은 방향으로 이어지며 GND→환류 다이오드→SW→L→출력의 경로를 사용합니다. 다이오드의 애노드는 GND, 캐소드는 SW입니다.

직접 바꿔 보기학습용 SVG 모형

해 보기: ON과 OFF를 번갈아 선택하고 피드백도 강조하세요.
예상 관찰: 스위치·다이오드의 전류 경로는 바뀌지만 L의 출력 방향은 같습니다.

실험 그림을 준비합니다.

교정: PCB 강의 PDF 79쪽 상단 ON/OFF 삽화는 제목과 달리 boost 연결입니다. 그대로 복제하지 않고 TPS54360의 buck 구조를 새로 그렸습니다.

입력 바이패스는 빠른 스위칭 전류를 가까이서 공급하고, 출력 C는 출력 리플을 줄이는 데 관여합니다. 이 그림은 정상 연속전류 모드(CCM)의 양의 인덕터 전류를 가정합니다. 기동·불연속 모드·역전류·정밀 제어 파형은 다루지 않습니다. SW 노드와 출력 DC 노드는 서로 다릅니다.

확인 문제 · OFF 동안 인덕터 전류가 즉시 0이 될까요?

이 CCM 모형에서는 그렇지 않습니다. 저장된 에너지로 같은 방향 전류가 이어지며 다이오드 환류 경로가 필요합니다.

EXPERIMENT 07

MCU 주변 부품을 역할로 읽습니다.

LDO는 입력과 출력의 전압 차를 주로 열로 소모하는 선형 레귤레이터입니다. 이 예는 5V→3.3V입니다. 입력·출력 커패시터의 값·ESR 조건은 해당 LDO 데이터시트에 맞춰야 합니다.

MCU 전원핀의 바이패스·디커플링 커패시터는 순간 전류의 가까운 경로를 마련합니다. DAC의 RC 필터는 신호 경로, 헤더는 외부 연결, EEPROM의 I²C는 통신 경로입니다. 회로도에서 커패시터가 한곳에 그려져 있어도 실제 PCB에서는 각 필요한 전원핀 가까이에 배치합니다.

직접 바꿔 보기학습용 SVG 모형

해 보기: 주변회로 블록을 바꾸고, 부하 전류와 바이패스 배치를 비교하세요.
예상 관찰: 역할에 맞는 경로가 강조되고, 부하가 커지면 LDO의 이상 손실이 증가합니다.

실험 그림을 준비합니다.

5V→3.3V·부하 전류는 이 계산 실험의 입력입니다. 온도·드롭아웃·안정성 합격을 판정하지 않습니다.

P≈(Vin−Vout)×I는 정지전류 등을 제외한 LDO 손실입니다. 이를 곧바로 온도로 바꾸려면 실제 열저항·구리·환경이 필요합니다. 100nF는 흔한 예일 뿐 모든 핀·모든 주파수에 통하는 정답이 아닙니다. 커패시턴스와 전압 정격, DC bias 영향, ESR/ESL, 귀환 경로를 함께 봅니다.

확인 문제 · 회로도에서 전원 net이 같으면 멀리 둔 커패시터도 똑같을까요?

논리적으로 연결돼도 빠른 전류에서는 경로의 기생 성분이 다릅니다. 부품값과 함께 실제 루프 배치를 봐야 합니다.

근거: 132강 0:05–8:12 · 141강 0:03–2:52 · 원문 교정·모형 경계

EXPERIMENT 08

보드 판본을 바꾸면 부품과 수치도 함께 바뀝니다.

비슷한 인버터 회로라도 자료의 판본이 다르면 게이트 드라이버, MOSFET, 션트와 증폭 이득이 다릅니다. 션트(shunt)는 전류를 작은 전압으로 바꾸는 저항이고, 증폭기는 그 전압을 ADC가 읽기 좋은 범위로 확대합니다.

A는 인버터 하드웨어 강의 PDF, B는 소형보드 B-Kit 회로도입니다. 두 사례 모두 여기서는 1.65V 오프셋을 둔 이상식 Vout=1.65+I×Rshunt×gain만 계산합니다. 이는 실제 증폭기의 출력 스윙이나 ADC 정격 검증이 아닙니다.

실험 그림을 준비합니다.

1차 근거: 인버터하드웨어설계_ver0.1.pdf 52·70쪽 / 소형보드.pdf 1·3쪽. 원문은 공개본에 포함하지 않습니다.

A는 UCC27211 / SQJQ466, 2mΩ·22배·±35A 예시입니다. B는 IR2101STRPBF / IRF3205PBF, 10mΩ·15배·±10A 예시입니다. A의 션트와 B의 이득을 합쳐 제3의 검증된 회로처럼 설명하면 안 됩니다.

확인 문제 · B의 ±10A에서 이상 출력은 얼마일까요?

1.65±(10×0.010×15)로 0.15~3.15V입니다. 부품 공차·출력 스윙·열·ADC 한계는 별도입니다.
