📖 1. 반복 카운터(TIMx_RCR)는 왜 필요하고 어떻게 동작하는가?

● STM32 고급 타이머(TIM1, TIM8) 전용 기능: 일반 범용 타이머(TIM2~5)에는 없고 오직 모터 제어용 고급 타이머에만 존재하는 특수 레지스터입니다.

💡 RCR 동작의 3단계 흐름:
  1. 사용자가 TIMx_RCR에 값 $N$을 미리 적어둡니다. (예: $N=1$)
  2. 카운터가 돌며 오버플로우(꼭대기)나 언더플로우(바닥)를 만날 때마다 RCR 섀도우 값이 1씩 감소(Down-count)합니다.
  3. RCR 값이 $0$에 도달하는 순간! 비로소 하드웨어가 업데이트 이벤트(UEV)를 발생시켜 인터럽트를 걸거나 ADC를 격발합니다. 이후 RCR은 다시 $N$으로 리로드됩니다.

⚠️ RCR이 없다면? 20kHz 중앙 정렬 PWM에서 꼭대기(ARR)와 바닥(0) 양쪽에서 매번 UEV가 터져 1초에 무려 40,000회 인터럽트가 발생하여 CPU가 다른 일을 전혀 못 하고 멈추게 됩니다.

🎯 2. "Center-aligned 모드에서 RCR이 홀수이면 1가지에서만 동작"의 비밀

중앙 정렬 모드(Center-aligned)는 카운터가 0 → ARR(오버플로우) → 0(언더플로우)를 무한 반복합니다. 즉, 이벤트 후보 지점은 [꼭대기] ↔ [바닥]이 번갈아(짝을 지어) 나타납니다.

RCR 설정 이벤트 만날 때 RCR 동작 UEV 발생 시점 (결과)
RCR = 0 도장 0개 필요 → 만나는 족족 발생 꼭대기 & 바닥 둘 다 (주기당 2회)
RCR = 1 (홀수★) 1회 건너뛰고 2번째마다 0 도달 꼭대기에서만 딱 1회! (또는 바닥만)
RCR = 2 (짝수) 2회 건너뛰고 3번째마다 0 도달 꼭대기 → 바닥 → 꼭대기 번갈아 발생
RCR = 3 (홀수) 3회 건너뛰고 4번째마다 0 도달 꼭대기에서만 2주기에 1회 발생!
👉 "카운터 시작 전 vs 시작 후 설정": 카운터가 0에서 위로 출발하므로, 타이머 시작 전에 RCR=1을 주면 첫 번째로 만나는 꼭대기(오버플로우)에 동기화됩니다. 타이머 동작 도중에 쓰면 다음 바닥(언더플로우)에 맞춰지게 됩니다.

🛡️ 3. 전동 킥보드 하드웨어와의 완벽한 연결 (암 쇼트 방지 & 노이즈 0% ADC 측정)

🔥 1. 암 쇼트(Arm Short)의 위험

3상 인버터의 한 상(Phase)에서 상단 MOSFET(High-side)과 하단 MOSFET(Low-side)이 0.1마이크로초라도 동시에 켜지면 48V 배터리가 GND로 직통 쇼트되어 수백 A의 단락전류로 MOSFET이 폭발합니다.

⏱️ 2. 상보 PWM & 데드타임(Dead-time)

MOSFET은 켜지는 속도보다 꺼질 때 게이트 전하 방전 때문에 더 늦게 꺼집니다. 따라서 상단이 꺼진 후 하단이 켜지기 직전, "둘 다 확실하게 꺼져 있는 안전 공백 시간(Dead-time)"을 TIM1/8이 하드웨어로 자동 삽입합니다.

🎯 3. 왜 꼭대기(Crest)에서 ADC를 트리거하는가?

스위칭 순간에는 엄청난 전압/전류 스파이크(노이즈)가 튑니다. Center-aligned 삼각파의 정중앙 꼭대기(Crest)는 스위칭 노이즈가 완전히 사라지고 전류가 가장 평온하게 흐르는 "골든 타임"입니다. 이때 RCR=1로 발생한 UEV가 ADC를 자동 격발합니다!
