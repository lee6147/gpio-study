잠깐! 강사는 0x40020C00이나 0x14 같은 숫자를 외워서 치나요?

절대 외우지 않습니다! MCU 설명서(레퍼런스 매뉴얼)에서 딱 3가지 표(건물 주소 → 방 번호 → 스위치 번호)를 순서대로 찾아 적는 것입니다.

STEP 1 · 건물 입구 찾기 (Memory Map 표)

• 비유: 캠퍼스 지도에서 "GPIOD 동 건물"의 시작 주소를 찾습니다.
• 정석: 매뉴얼의 Memory Map 표에서 GPIOD 구역의 시작점(Base Address)이 0x4002 0C00임을 확인합니다. (클럭을 켜는 RCC 건물은 0x4002 3800)

STEP 2 · 방 번호 찾기 (Register Map 표)

• 비유: 건물 입구 안내판에서 "내가 갈 방이 입구에서 몇 걸음(오프셋) 뒤인가?"를 봅니다.
• 정석: GPIO register map 표에서 모드 설정방(MODER)은 Offset 0x00, 출력 전압 스위치방(ODR)은 Offset 0x14임을 확인해 시작주소에 더합니다.

STEP 3 · 스위치 칸 찾기 (Bit Field 표)

• 비유: 방 문을 열면 스위치 32개(0번~31번)가 있습니다. "3번 핀(PD3)과 연결된 스위치가 몇 번 칸인가?"를 봅니다.
• 정석: MODER에서는 6~7번 비트(1 << 6), ODR에서는 3번 비트(1 << 3)를 켜거나 끕니다.

• 정석: 포인터 수식 앞에 붙는 단항 연산자 *는 역참조 연산자(Dereference Operator)입니다. 실제 메모리 공간(L-value)에 접근하여 값을 읽고 쓸 수 있게 합니다.

핵심 보완! "왜 같은 PD3 핀인데 MODER는 1 << 6이고 ODR은 1 << 3인가요?"

강의 75에서 초보자가 가장 많이 헷갈리는 1비트 방(ODR) vs 2비트 방(MODER)의 차이와 비트 마스킹 연산을 직접 눌러서 체험해 보세요.

🔍 궁금증 해결: 핀 1개가 차지하는 스위치 칸 수가 레지스터마다 다릅니다!

💡 비유: 2지선다 방(ODR) vs 4지선다 방(MODER)
• ODR (출력 데이터 방): 질문이 "전기 켤래(1), 끌래(0)?" 2가지뿐이라 핀 1개당 스위치 1칸이면 됩니다. 그래서 PD3 = 3번 비트(1 << 3)입니다.
• MODER (모드 설정 방): 선택지가 4가지(입력 00, 출력 01, 대체기능 10, 아날로그 11)라서 핀 1개당 스위치 2칸씩 차지합니다! 그래서 PD3 = 2 × 3 = 6번·7번 비트(1 << 6)가 됩니다!
📘 정석: 비트 필드 폭(Bit-field Width) 공식
포트의 n번 핀 (PDn, n = 0 ~ 15)을 제어할 때:
• 1-Bit 필드 레지스터 (ODR, IDR, OTYPER): 목표 비트 = Bit n ➔ (1UL << n)
• 2-Bit 필드 레지스터 (MODER, OSPEEDR, PUPDR): 목표 비트 쌍 = Bit [2n+1 : 2n] ➔ 출력 모드(01) 설정 시 하위 비트인 2n번 비트를 1로 세팅 (1UL << (2*n))
👇 아래에서 핀 번호(PD0 ~ PD7)를 터치해 보세요! MODER와 ODR의 시프트 숫자가 어떻게 달라지는지 즉시 계산됩니다.

🎛️ 다른 핀은 건드리지 않고 원하는 핀 스위치만 켜고 끄기 (|= vs &= ~ vs =)

👇 아래 8칸의 큼직한 스위치 박스를 직접 손가락/마우스로 터치해도 0(0V)과 1(3.3V)이 바뀝니다! (노란 테두리 = 위에서 선택한 목표 핀)

💡 강사 약식 코드(|=) vs 실전 펌웨어 안전 코드 비교

• 75강 강사 코드 (2.LED_OnOff_Register/main.c:41):
GPIOD->MODER |= (1 << 6);
➔ GPIOD는 리셋 직후 MODER 초기값이 0x00000000(모두 00)이라서 6번 비트만 1로 켜도 01(출력)이 됩니다. 하지만 만약 이전에 10(대체기능)이 들어있었다면 |=만 쓰면 11(아날로그)이 되는 버그가 생깁니다!

• 전동킥보드 실전 펌웨어 코드 (Core/Src/GPIO.c:10-11):
