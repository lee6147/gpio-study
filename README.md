# GPIO 실험 노트

STM32 GPIO 강의 내용을 기초부터 심화까지 단계적으로 익히는 오프라인·웹 학습 자료입니다.

- `index.html`: 학습 지도
- `basics.html`: LED 전류, 클럭·출력, 비트 마스크
- `io.html`: 스위치·풀업, 출력 방식·속도, 주소·포인터
- `advanced.html`: BSRR 경쟁, EXTI 인터럽트, PD3/PC6 보드 개정 디버깅

모든 시뮬레이션은 브라우저에서 동작하며 외부 라이브러리를 사용하지 않습니다. 실제 보드 실습 전에는 사용하는 보드의 LED 핀 개정(PD3→PC6)을 확인하세요.

강의 선별 기록과 상세 출처는 원본 프로젝트의 `AI_Workflows/gpio-study/`에 보존되어 있습니다.

## PCB 실험 노트 · 105–143강

`pcb-study-105-143/index.html`에서 회로도 → 부품 배치 → 배선 → 핵심 레이아웃 순서로 공부합니다. 6개 학습 페이지와 16개 조작 실험, 별도 출처·교정 페이지로 구성했습니다.

확인된 자료는 105–110, 130–135, 137–143의 19개 강의입니다. 111–129와 136은 원자료를 찾지 못해 내용을 추정하지 않았습니다. 원본 강의·전사·PDF는 이 저장소에 포함하지 않습니다.

계산은 명시된 이상 조건의 교육 모형이며 실제 온도·허용전류·EMC·제조 적합성을 검증하지 않습니다. 인터넷 없이 사용하려면 PCB 폴더의 HTML, CSS, JavaScript 파일을 함께 보관하세요. 모델 검사는 `node --test pcb-study-105-143/model.test.js`로 실행합니다.
